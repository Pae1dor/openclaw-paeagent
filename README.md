# 🦞 GoldHunter Trading System

ระบบเทรดทองคำ XAUUSD อัตโนมัติ ผสาน AI Agent สำหรับวิเคราะห์ข่าว และแจ้งเตือนผลเทรด

## 📌 Overview

โปรเจคนี้ประกอบด้วย 2 ส่วนหลัก:

1. **GoldHunter EA v3.0** — Expert Advisor บน MetaTrader 5 ที่เทรดอัตโนมัติด้วย 3 กลยุทธ์
2. **OpenClaw AI Agent (ก้ามแดง)** — AI Agent ที่สรุปข่าวตลาดทุกเช้า แจ้งเตือนผลเทรดผ่าน Telegram และแสดงผลบน Dashboard

## 🎯 Features

### EA GoldHunter v3.0 (MQL5)
- **Scalping** — RSI + EMA 5/13 Crossover (M5 Timeframe)
- **Trend Following** — EMA 21/55 Crossover + Trailing Stop (H1 Timeframe)
- **Breakout** — Donchian Channel 20 Period (M15 Timeframe)
- **News Filter** — หยุดเทรดช่วงข่าวแรง (NFP, CPI, FOMC)
- **Risk Management** — RR 1:1, SL/TP 50 points, Fixed Lot 0.02
- **Auto Logging** — เขียน CSV log สำหรับ AI Agent อ่าน
- **Push Notification** — แจ้งเตือนทุกครั้งที่เปิด/ปิด order
- **Daily Report** — สรุป Trades, Win/Loss, P&L อัตโนมัติทุกสิ้นวัน

### OpenClaw AI Agent (ก้ามแดง)
- **Morning Brief** — Cron job สรุปข่าวทองทุกเช้า 08:00 (Asia/Bangkok)
- **Trade Alert** — แจ้งเตือนผลเทรดผ่าน Telegram
- **Dashboard** — แสดงราคาทอง, Market Sessions, Watchlist, ข่าวสำคัญ
- **LLM Provider** — รองรับ DeepSeek / Claude / Gemini

## 🚀 Setup Guide

### 1. EA Installation
1. Copy `GoldHunter_EA.mq5` to `MQL5/Experts/` in MetaTrader 5
2. Open MetaEditor → Compile (F7)
3. Drag EA onto XAUUSD chart
4. Enable Algo Trading
5. ✅ Done!

### 2. OpenClaw Setup
1. Install OpenClaw: `irm https://openclaw.ai/install.ps1 | iex`
2. Run onboard: `openclaw onboard`
3. Set LLM provider (DeepSeek recommended for cost)
4. Pair Telegram bot
5. Set cron jobs for morning brief
6. ✅ Done!
